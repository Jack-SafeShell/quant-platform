# 分阶段路线

1. 平台基线与 Freqtrade 适配：已完成固定策略历史回测、芋道动态菜单、管理页面验收和实际引擎验证，不再重复选型评审。
2. 研究闭环：不可变策略版本、参数集复用、实验对比和行情数据质量报告已完成；下一步实现数据集下载任务和审计记录，再逐步引入参数优化及 AI 研究报告。每次实验应可重现，不以盈利作为唯一验收标准。
3. 模拟闭环：保持 dry-run，接入模拟账户、订单成交、持仓、风险校验、状态对账、异常恢复和告警；验证连续运行与任务幂等性。
4. 受控实盘评估：只有代码检查、历史回测、模拟盘、风险验证和人工确认全部完成，且获得另行明确指令，才评估受限执行、额度控制、停机和审计。当前不授权该阶段。
5. A 股扩展：行情、回测、信号与提醒优先；稳定、合规、可用接口明确后才评估自动交易。

Northstar 研究不阻塞第一阶段，保留适配替换空间。初期不拆微服务、不追求多引擎同时落地。

唯一推荐下一任务见 HANDOFF，未授权前不自行推进下一阶段业务实现。
