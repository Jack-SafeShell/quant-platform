# 分阶段路线

1. 平台基线与 Freqtrade 适配：已完成固定策略历史回测、芋道动态菜单、管理页面验收和实际引擎验证，不再重复选型评审。
2. 研究闭环：EMA 周期、止损和止盈可保存为不可变版本，已接通回测、报告、比较及评审批次绑定的模拟盘准备；不可变策略版本、参数集复用、实验对比、行情数据质量、受控下载审计、可复现报告、训练/验证排序、研究草稿导出和人工评审留痕已完成。每次实验应可重现，不以盈利作为唯一验收标准。
3. 模拟闭环：保持 dry-run；模拟资产/订单/持仓只读观测、固定风险基线、状态监控、异常恢复、告警处置、连续运行、任务幂等性、独立订单账本、状态对账、未知状态处理、故障演练和风险精确停止已经完成。
4. 受控实盘：准入报告、密钥边界、双确认、硬限额/幂等/紧急停机、DPAPI 凭据、OKX 私有 REST、首笔真实订单闭环和固定策略自动会话已完成。默认双开关关闭；管理页会话控制、统一运行面板、历史会话证据及近期账户权益曲线已完成。定时测试已结束，证据与限制见 HANDOFF。
5. 数字货币后续主线：策略实验工作台已支持 2–5 个版本共享条件比较及模拟会话准备。部署后运行候选方案模拟盘，补齐策略级成交、手续费、仓位及收益归因，再将合适的配置版本接入受控实盘，扩展策略模板和数字货币交易对。按业务闭环整合推进，不重复拆分同一阶段的评审文档。
6. A 股扩展：按用户要求暂缓开发，当前资源集中在数字货币研究与运行。

Northstar 研究不阻塞第一阶段，保留适配替换空间。初期不拆微服务、不追求多引擎同时落地。
