# 分阶段路线

1. 平台基线与 Freqtrade 适配：已完成固定策略历史回测、芋道动态菜单、管理页面验收和实际引擎验证，不再重复选型评审。
2. 研究闭环：不可变策略版本、参数集复用、实验对比、行情数据质量、受控下载审计、可复现报告、训练/验证排序、研究草稿导出和人工评审留痕已完成。每次实验应可重现，不以盈利作为唯一验收标准。
3. 模拟闭环：保持 dry-run；模拟资产/订单/持仓只读观测、固定风险基线、状态监控、异常恢复、告警处置、连续运行、任务幂等性、独立订单账本、状态对账、未知状态处理、故障演练和风险精确停止已经完成。
4. 受控实盘：准入报告、密钥边界、双确认、硬限额/幂等/紧急停机、DPAPI 凭据、OKX 私有 REST、首笔真实订单闭环和固定策略自动会话已完成。默认双开关关闭；下一步补齐管理页会话控制和 24 小时小额无人值守验收。
5. A 股扩展：行情、回测、信号与提醒优先；稳定、合规、可用接口明确后才评估自动交易。

Northstar 研究不阻塞第一阶段，保留适配替换空间。初期不拆微服务、不追求多引擎同时落地。

唯一推荐下一任务见 HANDOFF，未授权前不自行推进下一阶段业务实现。
