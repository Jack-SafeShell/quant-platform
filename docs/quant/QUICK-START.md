## 打开页面，查看已有结果

可先打开[量化工作台](http://127.0.0.1:5173/quant/operations)：顶部有“历史回看 / 策略比较 / 实盘管理”三个入口，并直接显示执行账户、密钥状态和交易开关。下方查看历史会话、收益、持仓估值、订单和告警；“记录所属账户”只改变查看范围，不切换交易账户。停止后的数字有历史时间标记，不代表当前余额；缺少数据显示“—”，不按零收益处理。

1. 打开[历史回看](http://127.0.0.1:5173/quant/backtest)，按现有账户登录。找到“查看历史回看结果（最近100次）”，选择已完成记录，点击“查看结果”。最近100次不是全部历史任务；本轮完整来源在下方报告。
2. 在“这次历史回看赚亏如何？”中先看净赚亏、最大回撤和成交数，再看历史复盘。点击成交表的“看这笔”定位买卖位置和卖出原因；没有成交不代表策略有优势。
3. 比较已有结果时，勾选2～5个相同资金、日期、币种和周期的成功任务，点“比较勾选的结果”。[多策略比较](http://127.0.0.1:5173/quant/experiments)可查看已有实验的“查看结果”；“多时段候选评估”可选2～4个同候选、同资金、验证日期不重叠的已完成实验，点“评估候选”，查看最差基础/压力收益，再“导出评估证据”。这是研究计算，不会启用交易。

**持币对比口径要先核对：** 页面历史复盘的“一直持币”按全部本金买入，只计所选手续费、不计额外滑点。本轮[同投入报告](BUYHOLD-COMPARISON.md)则只买100、其余约900闲置，并计算三档费用。两者回答不同问题，数字不能直接混用。最大回撤表示历史资产从高点的回落，不是未来亏损上限。

## 以后确实需要新回看时

在“设置一次历史回看”依次选①买卖策略、②历史行情、③回看日期，填假设本金、每次买入及单边手续费，再点“开始历史回看”。优先使用已准备的行情；日期统一UTC（00:00对应北京时间08:00），结束日不含。这会创建历史计算任务，不需要交易所密钥。先确定要回答的问题和固定条件；本轮无需重跑、修改策略或扫描参数。
