- 已完成回测实验报告导出：成功任务可下载 Markdown 报告和 JSON 可复现清单，包含策略版本及摘要、请求参数、行情来源及摘要、引擎镜像及版本、产物摘要和核心指标；清单自带 SHA-256，且不暴露策略源码。
- 新增受控优化批次：一次仅允许 2 至 5 个既有参数集，每个参数集分别生成训练和验证任务；两段区间不重叠、各至少 7 天、总长不超过 366 天，继续复用原持久回测队列和用户隔离。
- 优化批次仅在全部成员任务结束后生成汇总，按验证集收益率排序，同时展示训练/验证收益差、验证回撤、成交数和失败状态；系统明确不自动采纳参数。
- 批次结果附带规则驱动的中文研究草稿，固定记录证据 SHA-256、规则版本、结论、失败/过拟合/小样本风险和人工复核清单；草稿不调用外部 AI，不自动修改策略或参数。
- 研究草稿可导出 Markdown；接受/拒绝及意见以追加记录留痕，并绑定当时证据摘要。接受仅表示研究结论已评审，不会自动应用参数或进入模拟盘。
- 新增只读模拟盘准入清单：校验批次完整、当前研究证据已接受、样本外收益、成交样本数和过拟合差异；清单证据使用 SHA-256 固化，READY/NOT_READY 由人工追加确认。接口和页面始终返回 `activationAllowed=false`，不会启动 dry-run、读取凭据或创建订单。
- 新增模拟盘会话与启动审批门禁：用户必须从有效验证结果中明确选择参数集，且当前准入证据已有 READY 确认；会话绑定批次、策略版本、参数集及准入摘要，APPROVED/REJECTED 采用原子状态变更和追加审计。即使批准，执行能力仍固定关闭。
- 已批准会话可生成凭据无关的 dry-run 配置与就绪快照，检查准入证据、执行总开关、固定镜像摘要、Docker CLI、工作目录及配置敏感字段；快照正文和 SHA-256 持久留痕。单体配置将 `paper-execution-enabled` 固定为 false，不提供环境变量开启方式。
- 新增模拟盘执行计划状态机：最新就绪快照通过后才能创建，初始状态固定为 WAITING_ENABLE，绑定会话、快照摘要及唯一容器名；停止操作按当前租户、用户和任务 ID 原子转为 STOPPED，并追加前后状态与原因审计。当前不会进入 STARTING/RUNNING，也不会调用 Docker。

1. RDS 已执行芋道基础脚本和 Quartz 脚本；当前包含 system、infra、Quartz 与十六张 quant 表。量化动态菜单及全部增量迁移已应用。

4. 固定策略、BTC/USDT 现货 1h，已有受控参数批次但无策略编辑、模拟交易运行时、用户取消、自动重试或实盘。Binance 适配允许同格式数据，但本轮只有 OKX 实测。
5. 根 Spring Boot 4.1.0 / BOM 4.1.1 原样保留。聚合 package 后各 server 模块会生成可执行 JAR；本地启动需先以 `-Dspring-boot.repackage.skip=true clean install` 安装普通模块 JAR，再从 `yudao-server` 执行 `spring-boot:run`。
6. application-local.yaml 与前端 .env.local 为既有跟踪配置；现有测试 RDS useSSL=false、local mock-enable=true 未修改。正式环境前需另行治理。
