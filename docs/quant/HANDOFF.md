- 批次结果附带规则驱动的中文研究草稿，固定记录证据 SHA-256、规则版本、结论、失败/过拟合/小样本风险和人工复核清单；草稿不调用外部 AI，不自动修改策略或参数。
- 研究草稿可导出 Markdown；接受/拒绝及意见以追加记录留痕，并绑定当时证据摘要。接受仅表示研究结论已评审，不会自动应用参数或进入模拟盘。
- 新增只读模拟盘准入清单：校验批次完整、当前研究证据已接受、样本外收益、成交样本数和过拟合差异；清单证据使用 SHA-256 固化，READY/NOT_READY 由人工追加确认。接口和页面始终返回 `activationAllowed=false`，不会启动 dry-run、读取凭据或创建订单。
- 新增模拟盘会话与启动审批门禁：用户必须从有效验证结果中明确选择参数集，且当前准入证据已有 READY 确认；会话绑定批次、策略版本、参数集及准入摘要，APPROVED/REJECTED 采用原子状态变更和追加审计。即使批准，执行能力仍固定关闭。
- 已批准会话可生成凭据无关的 dry-run 配置与就绪快照，检查准入证据、执行总开关、固定镜像摘要、Docker CLI、工作目录及配置敏感字段；快照正文和 SHA-256 持久留痕。单体配置将 `paper-execution-enabled` 固定为 false，不提供环境变量开启方式。
- 新增模拟盘执行计划状态机：最新就绪快照通过后才能创建，初始状态固定为 WAITING_ENABLE，绑定会话、快照摘要及唯一容器名；停止操作按当前租户、用户和任务 ID 原子转为 STOPPED，并追加前后状态与原因审计。
- 新增 dry-run 执行适配预览：再次校验会话审批、就绪快照和不可变策略摘要，在隔离工作目录生成无凭据配置与策略文件；持久化带 SHA-256 的参数数组命令，固定镜像、唯一容器名、只读根文件系统、资源限制、无端口发布，并明确记录 `executed=false`。页面可查看预览，仍不调用 Docker。
- 新增启动前二次人工确认与一次性令牌：确认语和意见绑定当前命令预览摘要，令牌 5 分钟有效且明文仅返回一次，数据库只保存 SHA-256；并发签发按执行计划加锁，重签吊销旧令牌，停止计划也会吊销未消费令牌，消费由条件更新保证至多成功一次。当前仅提供签发和状态查询 API，执行总开关仍固定关闭。
- 新增受总开关保护的 dry-run 执行器：启动事务再次校验预览摘要、隔离目录、配置和策略文件摘要及受控命令，原子消费令牌并进入 STARTING；进程启动后进入 RUNNING，意外退出转 FAILED，人工停止转 STOPPED。应用重启会按唯一容器名请求停止遗留任务并标记 FAILED，不自动恢复。测试使用进程替身覆盖启动、停止和重启恢复；单体总开关仍固定关闭，本轮没有启动真实容器。
- 新增模拟盘只读观测与启动前检查报告：按租户和用户返回任务状态、受控文件及命令检查、最多 200 行/64 KiB 的专属运行日志尾部；日志路径由执行 ID 固定推导，拒绝任意路径。页面可刷新检查和日志，临时单进程开启及精确停止/回滚步骤已写入 BACKTEST；仓库总开关仍为 false。
- 已完成首个真实 Freqtrade dry-run 启停闭环。预览配置补齐固定可写 SQLite、显式定价、静态交易对、容器代理和 `initial_state=running`，省略默认关闭且会触发新版条件校验的 API/Telegram 对象；Docker 根文件系统继续只读、无凭据、无端口发布。行情下载增加瞬时网络错误重试。
- 模拟盘已与回测统一禁用交易所 WebSocket，使用受控 HTTP 代理请求公开行情；状态接口只读隔离 SQLite，返回估算余额、持仓、订单、已结交易、已实现收益和最近钱包记录，并从日志返回最后心跳、最后行情活动、网络/致命错误数及 60 秒稳定性判定。页面已展示这些字段，不开放 Freqtrade API 或端口。
- 新增模拟盘周期观测与站内告警：单体每 60 秒为活动执行固化心跳、行情、余额、持仓、订单及证据摘要，最多查询最近 100 条；陈旧心跳、网络错误、致命错误和进程意外退出按任务及类型幂等更新 OPEN/RESOLVED 告警。查询继续限定租户和用户，页面集中展示未恢复告警和快照。
- 模拟盘复验支持顺序创建：同一有效会话仅复用非终态执行，STOPPED/FAILED 后可创建新执行；准入证据变化时保留旧会话及其审计，按当前 READY 证据创建新会话。数据库唯一约束改为查询索引，服务层仍阻止同一会话出现多个活动执行。
