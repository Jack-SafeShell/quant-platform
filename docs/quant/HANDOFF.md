- 新增 dry-run 执行适配预览：再次校验会话审批、就绪快照和不可变策略摘要，在隔离工作目录生成无凭据配置与策略文件；持久化带 SHA-256 的参数数组命令，固定镜像、唯一容器名、只读根文件系统、资源限制、无端口发布，并明确记录 `executed=false`。页面可查看预览，仍不调用 Docker。
- 新增启动前二次人工确认与一次性令牌：确认语和意见绑定当前命令预览摘要，令牌 5 分钟有效且明文仅返回一次，数据库只保存 SHA-256；并发签发按执行计划加锁，重签吊销旧令牌，停止计划也会吊销未消费令牌，消费由条件更新保证至多成功一次。当前仅提供签发和状态查询 API，执行总开关仍固定关闭。
- 新增受总开关保护的 dry-run 执行器：启动事务再次校验预览摘要、隔离目录、配置和策略文件摘要及受控命令，原子消费令牌并进入 STARTING；进程启动后进入 RUNNING，意外退出转 FAILED，人工停止转 STOPPED。应用重启会按唯一容器名请求停止遗留任务并标记 FAILED，不自动恢复。测试使用进程替身覆盖启动、停止和重启恢复；单体总开关仍固定关闭，本轮没有启动真实容器。
- 新增模拟盘只读观测与启动前检查报告：按租户和用户返回任务状态、受控文件及命令检查、最多 200 行/64 KiB 的专属运行日志尾部；日志路径由执行 ID 固定推导，拒绝任意路径。页面可刷新检查和日志，临时单进程开启及精确停止/回滚步骤已写入 BACKTEST；仓库总开关仍为 false。

- 模拟盘已与回测统一禁用交易所 WebSocket，使用受控 HTTP 代理请求公开行情；状态接口只读隔离 SQLite，返回估算余额、持仓、订单、已结交易、已实现收益和最近钱包记录，并从日志返回最后心跳、最后行情活动、网络/致命错误数及 60 秒稳定性判定。页面已展示这些字段，不开放 Freqtrade API 或端口。
- 新增模拟盘周期观测与站内告警：单体每 60 秒为活动执行固化心跳、行情、余额、持仓、订单及证据摘要，最多查询最近 100 条；陈旧心跳、网络错误、致命错误和进程意外退出按任务及类型幂等更新 OPEN/RESOLVED 告警。查询继续限定租户和用户，页面集中展示未恢复告警和快照。

- 告警现支持 OPEN → ACKNOWLEDGED → RESOLVED 人工处置并记录操作人、说明、前后状态和时间；持续异常不会冲掉已确认状态，恢复后自动解决，再次发生会重开。终态分钟快照按 30 天策略每日清理，活动执行保留。
- 新增独立模拟订单账本与分钟级对账：以执行 ID 和 Freqtrade 来源订单 ID 生成 SHA-256 幂等键，统一 OPEN/FILLED/CANCELED/UNKNOWN 状态并追加变更审计；读取失败或未知订单产生高等级告警。风险越界会先留存告警，再按唯一容器名精确停止并追加执行审计。页面可查看订单账本和最近对账结果。
