# 同资金买入持有基准比较（2026-10-13）

本轮只复用两市场、三类策略的30份已有结果和公开行情，计算三档费用下的90组比较；没有新回测、下载、调参、服务重启或交易。

**基础成本下，固定突破在BTC/ETH都高于同投入买入持有；ETH净收益为正，BTC仍小幅亏损。压力成本下，三类策略的九个月净收益在两市场均落后于买入持有。** 目前没有足够稳定的增益证据，保持三类候选暂缓，不据此接受研究或启用交易。

## 小白读法

“比基准好”可能只是亏得较少，不等于赚了钱。例如BTC固定突破基础收益约-0.0530%，高于持有的-0.4885%，但仍低于本报告零利息现金参照0。以下收益率都按总本金1000计算，+1%约为+10 USDT。

同样1000本金、单笔投入100，策略经常空仓，买入持有一直持仓，实际平均暴露不同。相对收益差只回答这份历史中的差异，不能称风险调整后的Alpha或证明策略因果有效。

## 固定比较口径

- 数据/期间：Binance BTC/USDT、ETH/USDT现货1h，2026-01-01～10-01连续273天；另比较02-01～04-01、04-01～06-01、06-01～08-01、08-01～10-01四段，共242天。均UTC、右端不含。
- 总本金1000 USDT。量化策略沿用每笔名义投入100、最多1持仓；基准只买100名义金额，约900闲置，并以1000作收益分母。100按原价格计，不含入场费或滑点；各成本情景保持数量，额外成本从闲置现金扣除，实际入场支出略高于100。不拿1000全仓持币来直接对比低投入策略。
- 静态基准在第一根区间内K线开盘买入，按100/开盘价固定数量，在最后区间内K线收盘价结算，不加仓、不复利、不再平衡；闲置资金收益0。允许理论可分割数量，未按交易所最小数量/金额取整，不能当作可执行订单。
- 三档成本：原费率10/0、基础10/5、压力20/10（单边手续费/每边不利滑点，基点；10基点=0.10%、5基点=0.05%、20基点=0.20%）。量化使用原成交数量/时序，基准只有一轮买卖；均按同一固定现金流公式替换原手续费并重估滑点，不重复扣原费用，不重新触发信号或资金限制。
- 风险统一重建：初始权益1000，每小时按收盘价估值；现金计入权益，先结算已持仓退出，再记新入场，同小时新入新出正确结算，最终费用在期末结算。不是直接比较旧引擎回撤和买入持有浮亏。
- 分段原引擎的部分force_exit记在区间终点开盘。本轮保留这些实际价格/日期，独立结算，不删除成交或修改原回测；基准仍使用区间内最后收盘。五个RSI分段有此边界，其中两处价格差0.01 USDT，记录技术差异，不把窗口外后一小时收盘用于基准或估值。原V1计划保留，V2仅明确技术结算规则，不改策略/成本/资金。
