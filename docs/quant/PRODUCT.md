# 产品定位

供项目所有者长期使用的个人量化交易平台。最终目标是通过有纪律的量化交易追求资金价值增长：多方案筛选 → 模拟运行 → 受控实盘 → 成交、成本、收益与风险复盘。回测服务于选择交易方案，不能替代实际交易与持续收益评估，也不能保证盈利。

第一优先为数字货币，首先 OKX、Binance，接口允许后续扩展。能力覆盖行情接入、策略开发与版本管理、历史回测、参数优化、模拟交易、风险控制、自动下单、持仓、订单与成交记录、收益和风险分析、告警。

AI 辅助策略草案、回测解释、亏损归因、参数建议、多策略比较和研究报告；输出为可追溯的研究材料，不具有资金执行权限。

阶段边界：环境和构建基线之后，已实现固定策略历史回测最小闭环；继续完善管理后台运行验收，再逐步实现策略研究与模拟闭环。长期自动交易目标不等于当前实盘授权。

A 股第二阶段按用户要求暂缓开发，当前以数字货币为主；后续恢复时先做行情、回测、买卖信号与提醒；有稳定、合规、可用接口后，才评估自动交易。是否进入实盘必须经过 SECURITY 中的全套准入流程及所有者明确确认。

研究验收重视可复现：策略版本、参数、数据来源、时间范围、手续费、撮合语义与结果应关联；不能用空数据任务完成、零成交或单次正收益代替有效性验证。

策略实验工作台支持同一资金、手续费、行情及训练/验证区间下的 2–5 个 EMA 版本比较，并连接评审与模拟会话准备。后续开发围绕候选方案进入运行、成本扣除后的策略收益及风险归因；A 股继续暂缓。
